🗓️ Weekly refresh checklist (Wednesdays)
  1. Rate last week's meals when the prompt appears (⭐ 1–5, add a note, save favorites).
  2. Download the new Meijer ad PDF (and the Good Deal Days PDF).
  3. Open your chat with Claude, attach the PDFs, and paste the message below.
  4. Claude sends back an updated app file. Replace index.html in your GitHub Pages folder (see the README).
  5. Open the app, tap Update prices if you changed any by hand, then pick this week's meals.
